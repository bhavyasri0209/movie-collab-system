# 🎬 Movie Production Collaboration Platform

A full-stack movie production management platform built using Flask, MongoDB, SQLAlchemy, JWT Authentication, and Socket.IO.

---

# 🚀 Features

## 🔐 Authentication

* User Registration
* JWT Login System
* Role-Based Access

## 🎬 Project Management

* Create Projects
* Assign Crew Members
* Track Production Workflow

## 💬 Realtime Chat

* Crew Collaboration Chat
* Online User Tracking
* Notifications

## 📁 Asset Management

* Upload Production Assets
* Store Metadata in MongoDB
* Delete Assets

## 📅 Shoot Scheduling

* Create Shoot Schedules
* Manage Shoot Timings
* Production Calendar

## ✅ Task Management

* Assign Tasks
* Update Task Status
* Crew Task Dashboard

## 💰 Budget Tracking

* Add Production Expenses
* Budget Analytics
* Expense Reports

## 👨‍👩‍👧 Attendance System

* Mark Attendance
* Track Crew Presence

## 🎬 Scene Management

* Create Scenes
* Update Scene Status
* Track Shoot Progress

## 📈 Analytics Dashboard

* Task Analytics
* Scene Completion Charts
* Production Insights

## 🤖 AI Assistant

* Production Suggestions
* Crew Management Guidance
* Smart Workflow Tips

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/bhavyasri0209/movie-collab-platform.git
```

## Open Project

```bash
cd movie-collab-platform
```

## Install Requirements

```bash
pip install -r requirements.txt
```

## Run Application

```bash
python app.py
```

---

# 🔐 Environment Variables

Create environment variables:

* SECRET_KEY
* JWT_SECRET_KEY
* MONGO_URI
* SQLALCHEMY_DATABASE_URI
